## 一、小鹅通

### 开放平台概况

- 开放平台名称：**小鹅云（XiaoeCloud）**
- API 基础域名：`https://api.xiaoe-tech.com`
- Token 端点：`GET https://api.xiaoe-tech.com/token`
- 官方帮助中心：`https://helpcenter.xiaoe-tech.com`（大部分页面需商家账号登录）
- 官方 SDK（GitHub）：`https://github.com/xiaoeteam/XiaoeApiSDK`（PHP / Python / Java / Go）

### 认证方式

Client Credentials OAuth 2.0：

```
GET https://api.xiaoe-tech.com/token
  ?app_id=appXXX
  &client_id=xopXXX
  &secret_key=XXX
  &grant_type=client_credential
```

- Token 有效期 **2 小时**，到期需刷新
- 必须在商家后台配置**调用方 IP 白名单**，否则返回错误码 2051

### 可用接口（已确认）

| 分类 | 接口路径 | 说明 |
|------|----------|------|
| 用户 | `/xe.user.batch.get/2.0.0` | 批量拉取用户列表（分页，max 50/页，游标翻页） |
| 用户 | `/xe.user.info.get/1.0.0` | 单用户详情：手机、昵称、公司、职位、城市、消费金额、来源渠道 |
| 用户 | `/xe.user.register/1.0.0` | 注册新用户 |
| 用户 | `/xe.user.info.update/1.0.0` | 更新用户信息 |
| 订单 | `/xe.order.list.get/1.0.0` | 订单列表 |
| 订单 | `/xe.get.user.orders/1.0.0` | 指定用户的订单列表 |
| 订单 | `/xe.order.detail/1.0.0` | 订单详情 |
| 商品/课程 | `/xe.goods.detail.get/3.0.0` | 商品/课程详情（含学习进度 `learn_progress`） |
| 权益 | `/xe.product.available/1.0.0` | 查询用户是否购买某资源 |
| 直播 | `/xe.alive.user.list/1.0.0` | 直播间用户名单 |
| 打卡 | `/xe.elock.actor/1.0.0` | 打卡活动参与用户列表 |
| 分销 | `/xe.distributor.customer.get/1.0.0` | 分销客户信息 |

### Webhook 事件推送

- 支持 AES-CBC 加密推送（与微信公众号消息加密算法相同）
- 验签：`SHA1([token, timestamp, nonce, encrypt] 排序拼接)`
- 推送事件类型（如订单支付、用户注册）的完整枚举**在公开文档中未找到**，需后台文档确认

### 申请入口

商家后台 → 开放平台设置，获取 `app_id`、`client_id`、`secret_key`，并配置 IP 白名单。

### 评估小结

| 维度 | 状态 |
|------|------|
| 用户数据拉取 | ✅ 可用（手机、来源渠道、消费记录） |
| 订单同步 | ✅ 可用 |
| 实时 Webhook | ✅ 支持，事件枚举待确认 |
| 学习进度 | ✅ 商品详情接口含 `learn_progress` |
| 文档公开度 | ⚠️ 大多需商家账号登录查看 |
| SDK 支持 | ✅ 四语言官方 SDK |

## 二、螳螂营销云

### 公司背景

- 全称：**螳螂科技（Tangling Technology）**
- 定位：教育行业全链路智能营销 SaaS（营销云 + 销售云 + 客服云 + 教务云）
- 融资：A 轮近亿元（2022 年 4 月），SIG 领投

### 主要产品模块

| 模块 | 核心功能 |
|------|----------|
| 营销云 | 40+ 广告平台 API 自动对接、ROI 报表、落地页建站 |
| 销售云 / CRM | 线索自动分配（3 秒）、电销/网销打通、漏斗管理 |
| SCRM | 企业微信私域运营、活码引流、全链路私域闭环 |
| 教务云 | 付费后实时开课，营销到教务数据全打通 |

### 可用链接

- **官网**：当前**无法访问**（tangling.com / tangling.cn 均超时）
- **开放平台**：产品文档中提及"Open API 开放平台"，但无公开入口 URL
- **爱番番合作页**：螳螂科技是百度爱番番 CRM 开放平台首批合作服务商（可从爱番番侧确认）

### 已知集成能力（来自产品描述，未经 API 文档验证）

- 对接 40+ 广告商 API（百度、腾讯、字节跳动/飞鱼等），线索自动进线
- 与飞鱼外呼系统战略合作，支持通话记录实时同步
- 抖店等电商平台订单数据打通进 SCRM
- 教学系统集成：提供 API 接口及 SDK

### 评估小结

| 线索数据导出 | ❓ 功能存在，导出 API 待确认 |

## 三、需要向厂商获取的文档清单

### 3.1 小鹅通（优先级：高，信息较完整，可快速推进）

向商务 / 后台文档获取：

1. **Webhook 事件枚举表** — 支持哪些 event_type（订单支付、退款、用户注册、打卡完成等），以便配置实时触发
2. **API 完整字段字典** — 各接口的完整请求/响应字段（目前只有部分字段从 SDK 代码推断）
3. **调用频率限制（Rate Limit）** — QPS 上限、日调用量上限，影响全量同步方案设计
4. **分页游标机制说明** — `es_skip` 游标的边界行为（是否支持断点续传？游标是否会过期？）
5. **测试/沙箱环境** — 是否有测试店铺或 Sandbox API 用于联调

### 3.2 螳螂营销云（优先级：高，当前最大阻塞点）

**先决条件**：联系螳螂科技商务或技术支持，说明是乐和现有客户需要做系统集成。

需要获取的文档：

1. **Open API 开放平台文档** — 完整 API 列表（特别是：线索导出、客户信息导出、跟进记录导出）
2. **认证方式说明** — API Key？OAuth 2.0？签名算法？
3. **数据导出接口覆盖范围** — 以下数据是否有对应导出接口：
   - 线索列表（来源渠道、进线时间、联系方式、分配状态）
   - 客户跟进记录（通话记录、跟进阶段）
   - 企业微信 SCRM 客户数据
   - 付费/开课状态（教务云数据）
4. **Webhook / 事件推送机制** — 是否支持线索进线、状态变更的实时推送？
5. **速率限制与 SLA** — 调用频率上限、数据延迟保证
6. **测试账号 / 沙箱环境** — 是否可提供测试环境进行联调

## 四、两平台数据匹配策略（初步结论）

- **主匹配键**：手机号（两端均有，是最可靠的唯一标识）
- **补充匹配**：若手机号缺失，考虑微信 openid（需确认螳螂侧是否存储）
- **冲突处理原则**：以螳螂为线索来源权威，以小鹅通为学习行为权威，CRM 做聚合
