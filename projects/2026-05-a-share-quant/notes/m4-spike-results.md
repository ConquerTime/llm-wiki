# M4 Spike · 结果与选型决策

> 2026-05-09。两种纯动量形态在 A 股全市场 10 年样本的对比。
> 规格：[[m4-spike-spec]]

## 1. TL;DR

**两个 Spike 全部惨败，且是"教科书式的惨败"**：

| Spike | 形态 | 累计 | 年化 | MDD | Sharpe | 换手 | 交易 |
|-------|------|------|------|------|--------|------|------|
| A | Top1 日频 | **-99.95%** | -53.39% | -99.96% | -1.02 | 161x/年 | 637 |
| B | Top10 月频 | **-99.10%** | -37.67% | -99.17% | -1.28 | 23x/年 | 2945 |
| 基准 HS300 | 指数 | +40% | +3.47% | -45.60% | — | — | — |

**两者都 -99%**，且 B 月频比 A 日频亏得更彻底（因为分散买入了 10 只 Top 动量股，全部都是冲高回落样本）。

![[m4-spike-nav.png]]

## 2. 这不是 bug，这是 A 股纯动量的经典失败模式

结论在 [[../deliverables/strategy-selection.md|strategy-selection §3.1]] 已经预警过：
> **趋势 / 动量主要风险**：震荡市反复打脸（2016、2018、部分 2023），风格切换时回撤加剧

Spike 直接撞上了三个**结构性陷阱**：

### 2.1 A 股的"动量反转"效应
- 美股动量因子之所以有效：大盘股的信息扩散慢 → 涨得好的继续涨
- A 股散户主导 + 强反转效应：**今日的 Top 20 日涨幅股，高概率是"冲高回落前的峰值"**
- Spike A 的 637 次交易里，绝大多数是"买在山顶、T+1 拿到次日开盘就砸"

### 2.2 次新股污染
- "上市 250 日"的负过滤本来就是为了剔次新，但 250 日的股票仍有大量 IPO 后 300-500 日的"妖股"
- 这些股票 20 日动量极大（短期爆炒）→ 被 Top 排名选中 → 买入当天即顶
- B 月频的 Top 10 里，**经常同时含 3-5 只"IPO 后 1 年暴涨股"**

### 2.3 T+1 + 月频反应迟钝
- A 频日策略：信号错了次日开盘能出（至少不会放烂）
- B 策略月频：一个月才能调仓一次，期间 Top 10 可能已经腰斩
- B 的 MDD -99%：买了 10 只，一个月等再调时已经全都腰斩到脚踝

### 2.4 2024.1 跳水作为验证
两条 NAV 在 2024.1 / 2024.9 / 2025.4 三个板块轮动点都有陡峭下跌段，符合 strategy-selection 标注的三个必须覆盖的压力期。

## 3. Spike 本身的修复记录

跑通过程中修了 2 个真 bug，不影响 hello-world：

### Bug 1：`build_universe` 的"上市日数"误用交易日 idx
- `trade_cal` 只覆盖 2016+，但大量股票 list_date 早于 2016
- 用 cal_array 的 searchsorted 算 list_trade_idx 都为 0
- 导致 today_idx - list_idx 总是 ≤ 36（样本期初期的交易日数）→ 合格池 = ∅
- 修：改用"日历日"计算 `asof - list_date`，不用交易日 idx

### Bug 2：`engine._execute_orders` 持仓无法换仓退出
- 原代码 `prices` dict 只装 `target_weights` 里的 code
- 当策略 target 完全变更（如 600610 → 002015）时，600610 不在 prices → 跳过不卖
- 导致持仓永远没退出（Spike A 修 bug 前只有 10 笔交易 = 引擎只"加仓"过）
- **这个 bug 不影响 hello-world**（hello-world 的策略 target 始终包含同一 ts_code）
- 修：`prices` 字典扩展为 `target_weights ∪ holdings`

## 4. 工程观察

### 全市场扫描的性能
- 全市场加载：`bars_long` 1060 万行，3.5s 拉完（DuckDB）

## 5. 选型决策树（按 spec §7）

决策树：

```
if A 或 B 任一 Sharpe >= 0.6 且 MDD < 50%: 选赢家 → M4 正式版
else if 都远不合格: 切备选方向
else if 都在及格边缘: 合并形态
```

**当前**：A Sharpe -1.02 MDD -99.96% / B Sharpe -1.28 MDD -99.17% → **都远不合格**。

按决策树第二分支应直接切备选方向"小市值多因子（进攻版）"。但 **不应该直接切**，因为：

1. **Spike 的惨败带有明确的可归因性**：三个结构性陷阱（反转 / 次新污染 / T+1+月频），不是"趋势方向本身不行"
2. **strategy-selection §3.3 的 M4 设计**明确写了 "事件驱动过滤器" + "ATR 止损 + 量价过滤"——Spike **只做了纯动量，一条都没加**
3. 正确读法：**Spike 证伪了"裸动量 Top K"，没证伪"趋势 + 过滤"**

## 6. M4 正式版的修改清单（在 Spike 基础上）

按重要性从高到低：

### 6.1 必须做（否则继续亏）

- [ ] **ATR 止损**：单票持仓若从买入价回撤 N × ATR20 则次日开盘卖出。先试 N=2
- [ ] **趋势过滤闸**：只在"沪深 300 高于 60 日均线"时开仓，否则空仓（大盘趋势闸）。单这一条就能避掉 2018/2024 两次大亏
- [ ] **涨停日不买入**：当日 open 或 close 已触涨停的股票从候选剔除（避免买在烟花顶）
- [ ] **次新股窗口扩到 500 交易日**：250 不够
- [ ] **动量信号改成"过去 20 日收益 - 过去 1 日收益"**：剔除当日涨停脉冲，只保留结构性趋势

### 6.2 应该做

- [ ] **多窗合成动量**：`w1·mom_20 + w2·mom_60 + w3·mom_120`，给长窗更大权重
- [ ] **波动调整**：除以 20 日 vol，变成"风险调整后动量"
- [ ] **换手控制**：月频下调仓时，只动"进入 Top 10 和跌出 Top 10 的边际位置"，保留中间稳定持仓

### 6.3 M5 再说

- [ ] 事件驱动强形式（公告 / 龙虎榜正向打分）——需要补公告数据管道
- [ ] 板块/风格中性化
- [ ] 交易成本细化（滑点模型）

## 7. 回到 strategy-selection 的锚点

决定：**M4 正式版 = Spike B（横截面 Top-K）底座 + §6.1 五项改造**。选 B 而不是 A 的理由：

- A 是 Top1 满仓，极端样本 → 实盘心理承受不了 -99 MDD 路径
- B 的分散（Top 10 等权）让改造后的容错更高
- B 月频是 A 股量化研究的主流节奏
- A 留作"上限测试"，如果改造版 B 跑出来 Sharpe 0.8+，再试 A 形态看上限

## 10. Spike C 追加 · 单变量对照：HS300 趋势闸

### 10.1 设计

Spike B 原样不动，仅加一条闸门：

```
每日：
  if HS300.close <= HS300.SMA(60): 立即空仓（不等换仓日）
  else: 沿用 Spike B 月频 Top10 动量逻辑
```

闸门开仓时间占比 **52.63%**（10 年中约一半时间允许持仓）。

### 10.2 结果

| | Spike B（裸）| Spike C（+闸门）| HS300 |
|---|---|---|---|
| 累计 | -99.10% | **-96.35%** | +40% |
| 年化 | -37.67% | **-28.28%** | +3.47% |
| MDD | -99.17% | **-96.95%** | -45.60% |
| Sharpe | -1.28 | **-1.09** | — |
| 年化换手 | 23.1x | 16.4x | — |
| 交易次数 | 2945 | 2375 | — |

![[m4-spike-c-gate.png]]

### 10.3 解读（这是本次对照的核心信息）

闸门**确有改善**但**救不活**：
- 暴露时间减少 47% → 换手与手续费相应减少
- 年化损失从 -37.67% → -28.28%（挽回约 9 个百分点）
- 但绝对量级仍在 -96%+，**量变没到质变**

**根本原因**（这一条定 M4 方向）：
- 闸门只降低了"空头段的暴露损失"
- 但**多头段选出的 Top 10 本身就是系统性亏损源**（动量反转 + 次新污染）
- 复合效应下，"暴露一半 × 每次暴露都亏" ≠ "不亏"

### 10.4 对 M4 方向的修正

**Spike C 实际上回答了原决策树的问题**：趋势闸不是关键变量。

正确的 M4 修改清单 = §6.1 五项里的**后三项**优先级更高：

| 改造项 | 预期作用 | 优先级 |
|------|---------|-------|
| **涨停日不买入** | 直接剪掉"买在烟花顶"的样本 | P0 |
| **动量信号 = 过去 20 日收益 − 过去 1 日收益** | 剔除当日涨停脉冲贡献 | P0 |
| **次新股窗口扩到 500 交易日** | 剪掉 IPO 后妖股爆炒阶段 | P0 |
| **ATR 止损** | 单票个位数回撤就出 → 避免 -99% 级别单票事故 | P0 |
| HS300 趋势闸（本 Spike C 验证过的）| 锦上添花，不是救命 | P1 |

**结论修正**：
- M4 正式版 = Spike B 底座 + 上述 **4 个 P0 改造**（闸门作为 P1 可选）
- 选型决策树的第二分支"远不合格 → 切备选"**不立刻执行**：Spike C 证明 MDD 可以从 -99% 挪到 -97%，说明修改空间存在
- 但若 P0 四项改造后仍无法把年化拉回正 → 再切备选

### 10.5 Spike 阶段结束

三个 Spike 总计证据链：

1. **A（Top1）**：裸动量在 A 股彻底爆炸（-99.95%）
2. **B（Top10）**：分散帮不上（-99.10%）
3. **C（B + 闸门）**：粗过滤只改善一点（-96.35%）

**共同结论**：必须在**选股层**动刀（P0 四项），不能靠外加闸门救。

M4 正式版按此启动。
