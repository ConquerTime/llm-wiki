# M2-branch · 存储赛道主题量化策略（沙盘）

> 2026-05-08 立项。**沙盘推演，不代表实盘计划**。与主线 M1→M4（通用趋势/事件驱动）平行。
> 结束条件：Phase 4 触发（见 §5.3）后本策略彻底退出。

## 1. 策略定位

**假设前提**：100 万全部押注存储赛道 + 收益最大化 + 做择时 + 大方向反转时彻底清仓。

**本策略目标**：
- 在"押满赛道"的假设下，设计**最大化预期收益**的配置 + 择时规则
- 所有规则量化化、可回测、可以在 M3 回测框架内验证
- 提供 Phase 4 退出机制，防断头

**本策略不是**：
- 价投、长期持有、自下而上选股
- 多赛道均衡配置
- 实盘交易计划（属于沙盘）

## 3. 策略三层结构

### 3.1 选股 alpha（静态配置，3 选 1）

**配置 A（激进弹性）**：德30/江25/佰15/东15/兆10/澜5
- 期望值 +9%，上行潜力 +100%，下行风险 -60%

**配置 B（均衡 - 沙盘推荐）**：澜20/深15/兆15/东10/君10/德15/江10/佰5
- 期望值 +12%，上行 +65%，下行 -40%

**配置 C（防御进攻）**：澜30/深20/兆20/君10/德10/东10
- 期望值 +13%，上行 +45%，下行 -25%

配置切换由综合得分决定（见 §3.2）。

### 3.2 择时 beta（四信号共振 → 仓位档位）

综合得分 = S1(颗粒) + S2(原厂) + S3(财务) + S4(技术)，范围 [-24, +16]。

| 信号层 | 数据源 | 打分范围 | 更新频率 |
|--------|-------|---------|---------|
| S1 颗粒价 | DRAMeXchange / TrendForce | [-6, +4] | 周 |
| S2 原厂股价 | 美光 MU、海力士 000660.KS | [-6, +4] | 日 |
| S3 财务阶段 | 本项目 DB（季报）| [-6, +3] | 季 |
| S4 技术面 | 本项目 DB（日线）| [-6, +5] | 日 |

**得分 → 仓位映射**：

| 得分 | 仓位 | 选用配置 |
|------|------|---------|
| ≥ +10 | 100% | A 激进 |
| +6 ~ +9 | 90% | A 或 B |
| +3 ~ +5 | 70% | B |
| 0 ~ +2 | 50% | C |
| -3 ~ -1 | 30% | C 防御 |
| -6 ~ -4 | 15% | 仅澜起 |
| ≤ -7 | 0% | 清仓 |

### 3.3 内部轮动 alpha（每月做）

```
每月月初：
  - 8 只池内按过去 20 日相对涨幅排序
  - 前 3 名 +50% 权重
  - 中 3 名标准权重
  - 后 2 名 -30% 权重
  - 连续 2 月排后 2 → 剔除
```

## 4. 各信号层打分细则

### S1 颗粒价
- NAND 现货价 4周连续上涨 → +2
- NAND 4周震荡 → 0
- NAND 4周连续下跌 → -3
- DRAM 同上规则 → 对称打分

### S2 原厂股价
- 美光 60 日线向上 + 20 日创新高 → +2
- 海力士 同上 → +2
- 原厂指数滞涨 > 4 周 → -1
- 原厂指数跌破 120 日线 → -3

### S3 财务阶段（每季报后更新）
- 赛道平均毛利率环比 > +5pp → +2
- 赛道平均毛利率环比 [-5pp, +5pp] → 0
- 赛道平均毛利率环比 < -5pp → -3
- 赛道经营现金流改善 → +1
- 赛道经营现金流恶化 → -1
- 赛道存货增速 > 60% → -2（见顶警示）

### S4 技术面
- 赛道等权指数 20/60/120 日线上 → 各 +1
- 周涨幅 > 10% + 成交放大 → +1
- 跌破 20/60/120 日线 → 各 -1/-2/-3
- 赛道相对沪深300 月度超额 > 10% → +1

## 5. 退出规则

### 5.1 硬清仓（任一触发立即执行）

- R1: S1 颗粒 ≤ -3
- R2: S2 原厂 ≤ -3
- R3: 赛道等权指数从阶段高点回撤 > 20%
- R4: 单月核心持仓跌破 120 日线
- R5: 季报赛道平均毛利率环比 < -15pp
- R6: 政策黑天鹅（制裁扩大）

### 5.2 软减仓（分层缓冲）

**单只**：
- 单周 -15% → 减该标的 30%
- 连续 2 周跑输板块 -10% → 减 50%
- 跌破 20 日线 + 放量 → 减 30%

**整体**：
- 高点回撤 10% → 整体仓位至 75%
- 高点回撤 15% → 整体仓位至 50%
- 高点回撤 20% → 触发 R3，清仓

### 5.3 Phase 4 确认（彻底退出）

三条中任两条满足即触发终极清仓 + 本策略退出：

1. NAND 现货价连续 3 周下跌 > 5%
2. 美光或海力士周 K 破前低 + 放量
3. 下一季度预告：赛道平均净利润环比 -30%
