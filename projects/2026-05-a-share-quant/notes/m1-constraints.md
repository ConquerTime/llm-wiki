# M1 · 个人约束与画像（选型锚点）

> 所有策略选型都要回到这张锚点表。M2+ 如果发现策略跑偏了画像，优先修正选型而不是修正画像。

## 画像（2026-05-08 对齐）

| 维度 | 取值 | 对策略选型的含义 |
|------|------|-----------------|
| 资金规模 | 100–500 万 | 排除**超小市值流动性套利**（冲击成本过高）；主流策略容量足够；单票满仓 = 5–25 万，适合集中持仓 5–20 只 |
| 盯盘时间 | 盘中高频可关注（非 tick） | **日内、事件驱动、折扇、打板、龙虎榜跟随**都可行；**不限于**周频再平衡 |
| 风险偏好 | 进攻型，年化 30%+、容忍 30%+ 回撤 | 偏**动量 / 趋势 / 小盘 / 高 Beta**；排除低波稳健型（8–15%）作为主线 |
| 方向倾向 | 无，要求全面调研 | M1 必须横向对比至少 5 类策略家族，给出推荐理由而不是个人偏好 |

## 从画像推导出的隐含约束

1. **可以且应该**做带杠杆效应的方向（小盘动量、打板、折扇），但杠杆不是通过券商融资，而是通过标的本身的高波动实现。
2. **不要**首版就走"大宽基指增"——年化预期天花板与风险偏好不匹配。
3. **不要**走市场中性（多空对冲），A 股做空受限 + 目标年化 30%+ 基本做不到纯中性。
4. **必须**做防御设计：30% 回撤容忍不代表"到 30% 才救"，实盘必须有硬止损 / 仓位控制，否则实际回撤容易滑到 50%+。
5. **不承诺**策略一定能跑到 30%+：30% 是目标、不是门槛。回测跑不到就调整目标或放弃方向，不硬凑。

## A 股共通的结构性约束（不随个人画像变）

- **T+1**：买入当日不能卖出，排除纯日内回转
- **涨跌停**：主板 ±10%、创业板/科创板 ±20%、ST ±5% — 打板策略的底层、也是趋势失效点
- **做空受限**：融券券源少且贵，基本等同"只能做多"
- **停牌 / 特停 / ST**：数据管道必须处理
- **分红送转 / 除权**：回测价格必须前复权或后复权，否则价格跳变误导策略
- **新股 / 次新股**：上市初期波动与规则特殊（开盘 5 日无涨跌停），通常要单独处理

## 开放问题（M2+ 需要解决）

- **2024 年量化监管新规**对高频申报、报撤比、程序化交易的限制，是否影响本项目所选方向？
- **融券规则变化**：当前融券成本与可融券源情况，影响"统计套利 / 市场中性"是否完全不可行。
- **实盘通道**：最终走哪个券商 API（华泰 / 国君 / Ptrade / QMT / 恒生 UFT），不同通道对策略延迟要求不同，反向约束策略设计。这些项目本身非目标，但**策略的延迟预算**要提前估。
