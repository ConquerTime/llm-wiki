# 实盘持仓纪律框架（草稿）

> 2026-05-08 创建。针对价投线（存储模组持仓）的纪律约束。等数据体检（`m1-holdings-checkup.md`）完成后升级到 `deliverables/holdings-discipline.md`。

## 0. 适用范围

- **适用**：价投线的股票账户（当前 = 德明利 + 江波龙）
- **不适用**：本项目的量化策略仓位（有独立的回测驱动规则）
- **隔离原则**：两条线物理隔离，心理上不互相救火

## 1. 背景与自我校准

### 1.1 认知事实（承认）

- 当前持仓 100% 存储模组 = 70% 德明利 + 30% 江波龙
- 自述方法论为"价投"，实际是"主题押注 + 中长期持有"
- 光模块曾持有 150% 获利了结，若一路持有至今可达 +700%，该卖飞经历构成 FOMO 情绪源
- 无明确买入依据、无明确退出条件、无仓位上限、无止损线

### 1.2 改进承诺

- 接受"我的行为是主题押注，不是价投"这一事实描述
- 不再用"价投"标签为情绪仓位提供心理掩护
- 接受纪律约束高于直觉和乐观判断

## 2. 仓位结构规则

### 2.1 敞口上限

| 维度 | 上限 | 当前值 | 差距 |
|------|------|--------|------|
| 单一赛道敞口 | ≤ 60% | 100% | -40pp |
| 单一标的仓位 | ≤ 30% | 德明利 70% | -40pp |
| 单一风格（小盘/题材）| ≤ 60% | 100% | -40pp |
| 现金 / 机会池 | ≥ 20% | 0% | +20pp |

### 2.2 组合构造原则

- 即使判断 100% 正确，仓位错配也会放大风险到不可承受的区间
- 凯利公式粗估：胜率 70% 的策略最优仓位 ~40%，超过即 overbet
- 任何单一叙事的敞口必须有兜底（现金或低相关仓位）

## 3. 买入 / 加仓规则

### 3.1 核心原则

**加仓必须基于新信息，不能基于股价。**

### 3.2 加仓触发条件

| 条件 | 是否加仓 | 加仓幅度 |
|------|---------|---------|
| 股价涨 | ❌ | 0 |
| 股价跌 | ❌ | 0 |
| 季报毛利率超预期 + 颗粒价仍上行 | ✅ | 5–10% |
| 数据中心营收占比环比提升 >5pp | ✅ | 5–10% |
| 存货周转天数回落但毛利率保持 | ✅ | 5–10% |
| 行业新玩家入局（验证赛道）| ✅ | 5% |
| 仅"我更看好了" | ❌ | 0 |

### 3.3 加仓前强制动作

每次加仓前，在决策日志中写下：
- 我基于什么**具体数据**加仓
- 数据来源是什么
- 如果数据反转，我将如何应对

**写不出具体数据，不加仓。**

## 4. 止盈规则（阶梯 + 基本面 + 技术 三层）

### 4.1 第一层 · 阶梯止盈

```
单只盈利 50%   → 减仓 20%（收回成本的一半）
单只盈利 100%  → 再减仓 20%（保留核心持仓）
单只盈利 200%  → 再减仓 20%（剩下 40% 是"不花钱的仓位"）
单只盈利 300%+ → 剩余全部让它飞，不再操作
```

好处：每到台阶都"落袋 + 保留子弹"，消除"全卖太可惜 / 不卖怕回撤"的纠结。

### 4.2 第二层 · 基本面止盈（逻辑破坏即清仓）

任一条件触发 → 清仓：
- 颗粒价格连续 2 个月下跌 >10%（**待数据体检确定阈值**）
- 公司季度毛利率环比下降 >5pp（**待数据体检验证历史波动区间**）
- 公司存货环比大增 + 毛利率下降（主动备货被套）
- 重大政策/制裁事件（如美国制裁 A 股模组厂）

### 4.3 第三层 · 趋势止盈（技术兜底）

- 跌破 120 日均线 + 成交量放大 → 减仓 50%
- 跌破 250 日均线 → 清仓

### 4.4 三层协同

任一层触发时，**其他两层同步检查**。不因"基本面看好"拒绝执行技术止损。

## 5. 止损规则

### 5.1 单只止损

| 亏损幅度 | 动作 |
|----------|------|
| -15% | 复查买入逻辑（不必卖）|
| -25% | 强制减仓 50% |
| -35% | 清仓 |

### 5.2 组合止损

| 组合亏损 | 动作 |
|---------|------|
| -20% | 降至 50% 仓位 + 去杠杆 |
| -30% | 全部清仓 + 休息 1 个月不看盘 |

### 5.3 "休息 1 个月"条款

大亏后的报复性交易是最危险的。强制冷却期用于：
- 让情绪回归基线
- 复盘失败原因
- 重新评估方法论

## 6. 反情绪机制

### 6.1 光模块遗憾隔离

**禁止心理**：
- "上次卖飞，这次要拿住"
- "错过一次，不能再错过"
- "我的嗅觉是对的，所以这次也对"

**强制冷却**：发现以上心理立即暂停交易 24 小时。

### 6.2 "切换吃波段"冷却

任何非触发条件的交易决策（包括切换标的、拉高减仓、回调加仓等），**冷却 3 天**。3 天后若决策依据仍清晰，再执行；若已不想做，即是情绪冲动。

### 6.3 月度复盘强制化

每月 1 次，文字记录：
- 本月交易清单
- 每笔交易的**事前依据**
- 事后被证明对 / 错的依据
- 有无"因为想赚钱"而非"因为依据"的动作
- 纪律是否被破坏，为什么

**不写下来不算复盘。**

## 7. 关键研究问题（待数据体检回答）

存储模组行业"低价存货用完后能不能继续赚"的核心争议：

| 情景 | 机制 | 识别信号 |
|------|------|---------|
| A. 周期见顶 | 库存用完遇颗粒价回落 | 存货周转骤降 + 毛利率跳水 |
| B. 议价传导 | 库存用完时涨价传导成功 | 存货周转正常 + 毛利率持平 |
| C. 量增抵消 | AI 需求驱动量价齐升 | 数据中心营收占比持续上升 |
