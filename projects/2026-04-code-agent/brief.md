# Code Agent 从零实现 · 简报

## 背景

Claude Code 是目前最强的 AI coding agent 之一，其泄露源码已在 GitHub 上广泛流传。
通过阅读源码 + 亲手从 0 实现，可以最深入地理解它的技术架构，而非仅停留在"使用者"视角。

## 目标

深入理解 Claude Code 的核心技术架构，并产出一个可运行的 code agent 原型，验证关键设计决策。

## 非目标

- 不是要完整复刻 Claude Code（太大，且无意义）
- 不是做一个生产级产品
- 不是走"教程"路线，而是通过实践驱动学习

## 范围

1. 收集和整理 Claude Code 泄露源码的关键资料
2. 分析核心架构：工具系统、REPL 循环、上下文管理、多 Agent 协作
3. 从 0 实现关键模块，验证自己的理解
4. 将调研结论和学到的模式回流到 wiki
