## slide01 — 封面

A lone developer sitting at a glowing terminal in a dark server room, seen from behind, lines of code cascading down multiple monitors, deep blue and teal ambient light.
/ Centered composition, subject occupies middle third, top 15% and bottom 15% fade to near-black void.
/ Cinematic, moody, desaturated except for cool teal highlights (hex #76C7C0) and amber terminal glow (hex #D4A574). Film grain texture, 16:9.
/ Do not include: text, logos, watermarks, faces, hands, bright white areas.
