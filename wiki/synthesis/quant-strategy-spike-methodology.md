# 量化策略 Spike 开发方法论

> 用 Spike 链（单变量实验 + 归因）代替"跑 1000 次参数扫描"来开发量化策略。配合调研先行 + 年度拆分 + α/β/运气分层，能在一天内完成一次从 Spike A 到 baseline 的探索，并把**反直觉发现**变成知识资产。

## 为什么写这一页

传统量化研究的失败模式有两种：

- **参数扫描派**：定一个因子，扫 100 组参数，挑最好的。回测漂亮但样本外崩
- **直觉派**：凭感觉堆因子、堆止损、堆过滤。每加一层都"感觉更好"，但没有归因

两者都无法回答一个核心问题：**"这个策略的收益，来自 α、β、还是运气？"**

本页整理一次完整策略探索（a-share-quant）里打磨出的**7 条开发模式 + 5 个反直觉发现**。核心是让回测**诚实可归因**。

## 七条开发模式

### 1. 调研先行比跑 1000 次回测省时

- **症状**：凭直觉启动一个"听起来合理"的策略，跑完一看累计 -99%
- **纠正**：进任何回测前先查 IC / ICIR 的**符号和数量级**。学术综述、Zhihu 专栏、券商研报都可
- **关键指标**：
  - IC 符号（信号方向对不对）
  - ICIR 量级（α 强度上限）
  - 时变性（牛/熊/震荡里的稳定性）
- **成本**：30 分钟的调研能省下 3 小时的 Spike

### 2. Spike 链 = 单变量实验 + 归因

- 每个 Spike **只改一个变量**，与前一版对照
- 例子：
  ```
  A (Top1) → B (Top10)      改持仓集中度
  B → D                      改信号方向（nlargest → nsmallest）
  D → E                      加市场状态闸门
  E → F                      加行业两层分散
  F → G                      加 ATR 止损
  F → H                      改残差信号
  H → H3                     改多窗合成
  ```
- 如果一步改两件事，好坏都说不清归因
- **Spike 命名用字母序号**（A/B/...）而非语义名，避免"你为啥叫它 momentum_v2"

### 3. 年度拆分 > 全样本指标

- 全样本累计 / MDD / Sharpe 能隐藏所有时变性
- 必出的一张表：策略 × 年度 × 基准 × 差值
- 例子：Spike D 全样本 -39% 看起来失败，年度拆分显示"**震荡年 4/4 全胜 / 单边牛市 4/4 全输**"，完美复现外部研究的"震荡市 ICIR +0.45 / 牛市 -0.36"
- **策略在什么市场里好、什么市场里差** 比"平均多好"重要 100 倍

### 4. 反直觉结果是调研信号，不是放弃信号

- 回测出"明显好"时警惕运气
- 回测出"明显差"时先诊断再放弃
- 每个反直觉都是**发现的入口**
- 例子：Spike G 加 ATR 止损后收益掉 46pp，"放弃 ATR"很容易，但**诊断后**发现 ATR 止损和反转假设方向相反——这是重要方法论

### 5. 诚实分层：α / β / 运气

每个策略必须显式回答"**你的收益来源是什么**"：

| 成分 | 剥离方式 |
|---|---|
| 市场 β | 对标市场指数做 OLS 取残差 |
| 风格 β | 小市值 / 高波 / 价值 等因子暴露 |
| 行业 β | 行业 dummy 或行业内 demean |
| α | 剥完以上后的残差 |
| 运气 | 剔除极端年样本外重测 |

**识别运气的核心操作：剔除样本期内最极端的那一年，重测**。如果核心指标（Sharpe / 累计）崩了，之前的"α" 其实是那一年的运气（例子：本项目 F 的 +67% 累计里 2016 贡献 +51%）

### 6. 验收线是"质量门"，不是"是否启动"的标准

- 策略不达验收线 ≠ 失败
- 它是一个**量化的 α 强度探针**，告诉你"这个方向的上限在哪"
- 例子：H3 Sharpe 0.13 告诉你"单因子反转 + 行业分散 + 月频"天花板大约在 0.1-0.2。这个信息在后续决策（加杠杆 / 多因子 / 切备选）时极有价值

### 7. 工程一次投入，策略一次性

- **引擎值得抽象**：每小时投入可节省后续 3-10 倍研究时间
- **策略不值得抽象**：每个 Spike 50-150 行策略代码，复制粘贴比抽象快
- 相关守则：[[karpathy-guidelines|Karpathy Guidelines]] §3.2 "不为一次性使用的代码创建抽象"

## 五个反直觉发现（案例集）

这些是 a-share-quant 项目 Spike 链里**打破事前假设的具体发现**。它们是方法论的"肉"——每一个都示范了"先 diagnose 再判决"的力量。

### #1 "裸动量"可能是反向策略

- **假设**：动量不够强 → 加过滤就好
- **实际**：A 股 20 日动量 ICIR **-0.244**。做多 Top 动量 = 做反向反转，数学上必然亏光
- **教训**：进回测前先验证信号 IC 符号

### #2 状态闸门方向由因子属性决定

- **假设**：大盘在均线上适合开仓（顺势）
- **实际**：反转因子在**震荡 / 熊市有效，单边牛市溃败**。闸门应该**反过来**（熊市开仓）
- 同一个闸门规则，方向颠倒收益差 **113pp**（Spike C -96% vs Spike E +16%）

### #3 止损逻辑必须和信号逻辑一致

- **假设**：加 ATR 止损能降 MDD
- **实际**：反转策略 + ATR 止损 = 反效果。ATR 在 V 形底把仓位卖飞
- 反转假设 = "跌的会反弹"；ATR 假设 = "继续跌就砍"；两者方向相反
- 倍数扫描（1.5 / 2.0 / 2.5 / 3.0 / 4.0 / ∞）单调趋势：**越松越好，最优 = 不加止损**

### #4 样本外稳定性 > 样本内"最佳"

- Spike F 累计 +67.70% 看起来是 baseline
- Spike H 剥市场 β 后 +32.97% 看似跑输
- **剔除 2016 一年**：F ex-2016 +8.66%，H ex-2016 +24.22% —— **真相反过来**
- F 的"最佳"依赖于 2016 熔断年的市场 β 大反弹（运气）
- **每个策略必须做 ex-极端年的稳定性检查**

### #5 "大胜覆盖小输"好过"全场景平均"

- Spike H3 多窗合成 vs H 单窗：**6 年胜 5 年输**（看起来不是稳胜）
- 但净值胜 20pp，因为**大胜年幅度远大于小输年**
- 不要追求"全场景最优"，要追求"劣势场景可接受 + 优势场景爆发"
- 市场的非对称性（下跌慢 / 反弹快）天然对"捕捉切换"的策略有利

## 适用范围与边界

**适用**：
- 任何基于规则的**因子/量化策略**探索
- Spike 链 3-10 次内能收敛
- 数据充足（至少覆盖一个完整周期）

**不适用**：
- ML 黑箱策略（调研 + 单变量归因都难）
- 微观结构 / 高频（时间尺度不一样）
- 主观策略
