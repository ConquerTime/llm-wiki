# open-agents

> Vercel 开源云端 Agent 构建模板

## 概述

open-agents 是 Vercel Labs 开源的多 Agent 构建模板，托管在 GitHub（vercel-labs/open-agents）。提供云端运行 AI Agent 的基础架构，支持多 Agent 协作和工作流编排。

## 关键特性

- **云端部署**：专为 Vercel 平台设计的 Agent 运行环境
- **多 Agent 模板**：开箱即用的多 Agent 协作框架
- **开源可扩展**：可基于模板二次开发
