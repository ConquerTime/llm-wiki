# 微信 JSAPI 支付接入：后台配置完整清单

> 适用于：在微信内置浏览器（公众号 H5 页面）中唤起微信支付。调研日期：2026-05-07。

---

## 一、需要注册/开通的账号与平台

### 1.1 微信公众平台账号（mp.weixin.qq.com）

**必须是服务号**（订阅号不支持支付），且需完成微信认证。

| 要求 | 说明 |
|------|------|
| 账号类型 | 服务号（企业类型）或政府/媒体类公众号 |
| 认证状态 | 必须完成微信认证（年费约 300 元，需企业资质） |
| 主体类型 | 个体工商户、企业、事业单位、政府机关、社会组织均可 |

### 1.2 微信支付商户号（pay.weixin.qq.com）

| 情况 | 操作 |
|------|------|
| 尚未有商户号 | 前往微信支付官网申请，绑定银行账户，完成入驻 |
| 已有商户号 | 超级管理员登录商户平台，申请开通 **JSAPI 支付产品权限** |

## 二、微信公众平台配置（mp.weixin.qq.com）

### 2.1 获取基础凭证

**设置与开发 → 基本配置**
- **AppID**：`wx` 开头的 18 位字符串
- **AppSecret**：32 位字符串，不可泄露

### 2.2 配置 IP 白名单

**设置与开发 → 基本配置 → IP 白名单**

填写服务器出口 IP，否则 `access_token` 接口调用会报错。

### 2.3 配置网页授权域名（获取 openid 必须）

**设置与开发 → 账号设置 → 功能设置 → 网页授权域名**

- 填写域名（如 `www.example.com`），不带协议和路径
- 需下载 `MP_verify_xxxxxx.txt` 放到域名根目录做验证
- 用途：通过 OAuth2.0 授权获取用户 openid（JSAPI 支付的必要参数）

### 2.4 配置 JS 接口安全域名（调用 JS-SDK 支付必须）

**设置与开发 → 账号设置 → 功能设置 → JS 接口安全域名**

- 最多 5 个域名，不支持 IP 和端口，域名需 ICP 备案
- 同样需在域名根目录放置验证文件
- 用途：网页使用 `wx.config()` 注入 JS-SDK 权限时必须在此名单内

## 三、微信商户平台配置（pay.weixin.qq.com）

超级管理员账号登录操作。

### 3.1 申请商户 API 证书

**账户中心 → API 安全 → 申请商户 API 证书**

使用官方"证书工具"生成，本地生成以下文件：

| 文件 | 用途 |
|------|------|
| `apiclient_cert.p12` | PKCS12 格式证书（含私钥） |
| `apiclient_cert.pem` | PEM 格式证书（含公钥） |
| `apiclient_key.pem` | 商户 API 证书私钥（签名请求用） |

**私钥文件严禁上传到 Git 仓库或嵌入前端代码，仅存于服务器。**

### 3.2 设置 APIv3 密钥

**账户中心 → 账户设置 → API 安全 → 设置 APIv3 密钥**

- 自定义 32 位字符串（数字 + 大小写字母组合）
- 设置后无法查看，只能重置，**设置时必须记录**
- 用途：解密微信支付回调通知中的加密数据（AES-256-GCM）

### 3.3 配置 JSAPI 支付授权目录

**产品中心 → 开发配置 → 支付授权目录**

- 填写所有会调起 JSAPI 支付的页面 URL **目录**（精确到目录级别）
- 例：支付页面是 `https://www.example.com/pay/checkout`，则填 `https://www.example.com/pay/`
- 支持配置多个目录
- **配置错误是最常见的支付失败原因**（报 `no_permission`）

### 3.4 支付回调通知地址

回调地址（`notify_url`）在每次下单 API 请求时动态传入，无需后台预配置，但需满足：
- 必须是 HTTPS 公网可访问地址
- 不超过 255 个字符

## 五、开发凭证清单

| 凭证名称 | 标识 | 获取位置 | 用途 |
|---------|------|---------|------|
| 公众号 AppID | `appid` | 公众平台 → 基本配置 | JSAPI 下单、JS-SDK wx.config |
| 公众号 AppSecret | `appsecret` | 公众平台 → 基本配置 | 换取 access_token，进而获取 openid |
| 商户号 | `mchid` | 商户平台注册后系统分配 | 所有支付 API 请求 |
| APIv3 密钥 | `apiv3_key` | 商户平台 → API 安全 | 解密回调通知 |
| 商户 API 证书私钥 | `apiclient_key.pem` | 申请证书时本地工具生成 | 签名所有 API 请求 |
| 商户 API 证书序列号 | `serial_no` | 从 `apiclient_cert.pem` 提取，或商户平台证书管理页查看 | 请求 Header 中标识使用的证书 |
| 微信支付公钥 | `wechatpay_public_key.pem` | 商户平台 → API 安全 → 微信支付公钥 | 验证微信签名（推荐替代平台证书） |
| 微信支付公钥 ID | `wechatpay_public_key_id` | 同上 | 与公钥配对使用 |

## 六、配置步骤顺序

```
1. 注册服务号 → 完成微信认证
2. 注册/入驻商户号 → 开通 JSAPI 支付产品权限
3. [商户平台] 发起 AppID 关联申请
4. [公众平台] 确认商户号绑定
5. [公众平台] 配置网页授权域名（含域名验证文件）
6. [公众平台] 配置 JS 接口安全域名（含域名验证文件）
7. [商户平台] 申请并下载商户 API 证书
8. [商户平台] 设置 APIv3 密钥
9. [商户平台] 配置 JSAPI 支付授权目录
10. 下载微信支付公钥
11. 汇总所有凭证，开始开发
```

## 七、常见坑点

- **授权目录精确匹配**：必须精确到目录级别，多一级或少一级都会报 `no_permission`
- **openid 归属 AppID**：下单传入的 openid 必须是通过同一 appid 授权获取的，跨 AppID 的 openid 无效
- **JS-SDK 签名用完整 URL**：`wx.config` 签名的 `url` 参数必须是当前页面完整 URL（含查询参数，不含 `#` 后的 hash 部分）
- **APIv3 密钥设置后不可查看**：丢失只能重置，重置会导致线上服务失效
- **证书私钥只存服务端**：`apiclient_key.pem` 严禁出现在前端代码、Git 仓库或任何公开位置
